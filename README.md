# Easy Translator

极简翻译软件：上面输入，下面出译文。

## 功能
- **文字翻译**：在上方输入，停顿约 0.7 秒自动翻译（`Ctrl+Enter` 立即翻译）
- **单词音标**：输入或译文是单个英文单词时，在译文上方显示英式/美式音标；不是单个单词时不显示
- **自动中⇄英**：目标语言选“自动（中⇄英）”时，输入中文翻成英文，输入英文翻成中文；也可以手动选其他语言
- **长文本**：自动按段落/句子分段并行翻译再拼接，几千上万字也能翻译，状态栏显示进度
- **截图翻译**（默认 `Ctrl+Alt+Q`）：框选屏幕区域，自动识别文字并翻译
- **划词翻译**（默认 `Ctrl+Alt+W`）：在任何软件里选中文字后按快捷键，直接翻译（不会改动你的剪贴板文字）
- **📌 置顶**：窗口保持在最前面
- **托盘常驻**：关闭窗口时缩到右下角托盘，快捷键仍可用；右键托盘图标退出
- **开机自启**：在“设置”中开启，开机后安静地待在托盘里

“设置”里可以修改两个快捷键、截图识别语言、托盘和开机自启。

## 翻译服务
依次尝试 Google 翻译的三个接口 → MyMemory，哪个能用就用哪个，并记住可用的那个（一个接口被限流时自动换下一个）。免费、无需注册，需要联网。

## 文字识别
使用 Windows 10/11 自带的 OCR，不联网、免费。识别前会自动放大图片以提高小字准确度。
“自动”模式会同时用中文和英文识别，再挑更合适的结果。
如果选择的识别语言没有安装：Windows 设置 → 时间和语言 → 语言和区域 → 添加语言。

## 获取 exe
**方式一（推荐）**：打开 GitHub 仓库的 **Actions** 页 → 最新一次 “Build Windows exe” → 页面底部 Artifacts 下载 `EasyTranslator`，解压得到 `EasyTranslator.exe`，双击即可运行。

**方式二**：在 Windows 上安装 Python 3，双击 `build.bat`，生成 `dist\EasyTranslator.exe`。
